2. Create GitHub repo `BlindRunway`.
3. Copy this whole folder into the repo root (or merge `docs/`, `levels/`, `prompts/`, `docs/placeholders/`).
4. Open Unity Hub → New **3D (URP)** project **inside** that repo folder named `BlindRunway` if not already a Unity project.
5. Open the repo in Claude / Cursor.
6. Paste **`prompts/CLAUDE-MASTER-PROMPT.md`** as the only task.
7. One agent. Microcommits. Push `main`. Stop after Levels 1–5.

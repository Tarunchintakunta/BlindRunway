# Level 03 — “Banana in the Hold”
**Theme:** Cargo chaos. Homage wink to BOMBANANA without copying.  
**Duration:** ~6 min

## Setup
- Cargo net breaks; bananas (crates) slide; shift CoG
- Pilot feels sluggish pitch if crates unsecured
- Cabin must re-strap 3 crates while plane maneuvers

## Objectives
- Secure all crates (Cabin)
- Navigator calls pitch trim changes as CoG updates
- Land with ≥2 crates secured

## UI
- Cabin: crate secure progress rings
- Navigator: CoG diamond drifts on instrument

## Failures
- All crates loose at touchdown, CoG tip stall comedy fail

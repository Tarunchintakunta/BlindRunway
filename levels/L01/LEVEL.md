# Level 01 — “Clear Skies (Lying)”
**Theme:** Tutorial night approach. Calm weather. Teaches voice loop.  
**Duration:** ~4 min  
**Unlock:** default

## Setup
- Short final approach, wide runway, full fuel, no wind
- Cabin: 4 calm passengers, 1 loose bag

## Objectives
1. Navigator reads altitude every 500 ft; Pilot follows voice
2. Gear down before 500 ft AGL
3. Cabin straps bag before touchdown
4. Land in gate box

## Failures
- Gear up landing, runway miss, timer

## UI beats
- First-time coach marks: “Navigator: hold R to ping”, “Pilot: trust the voice”
- Soft glow on gear switch when Navigator pings it

## Win feel
One star easy; three stars if cabin secure 100% + centerline
